# Project 57: Gaming Tournament Portal (NexusArena)

An esports tournament management and live interactive championship platform built with **React 18 + Vite 5 + Tailwind CSS 3.4 + Zustand 4.5**.

## Features
- **Interactive Tournament Bracket Tree**: Quarterfinals, Semifinals, and Grand Finals tree visualization with score tracking and round progression.
- **Squad Registration & Roster Builder**: Clan registration with captain verification, Discord tags, and 5-man rosters.
- **Live Spectator Arena**: Broadcast stream frame with live chat reaction feed and viewer metrics.
- **Official Referee Desk**: Instant map score updates and dispute settlement.
- **Prize Pool Escrow**: Transparent reward distribution across champion and runner-up tiers.
